# SQL Monitor 仕様書

**Version:** v0.1 Draft  
**Project:** SQL Monitor  
**Organization:** Sapporo Quake Lab

---

# 1. 概要

SQL Monitorは、地震観測機から取得した観測データを表示・記録し、
サーバーへ送信するためのクライアントソフトウェアです。

---

# 2. 対象OS

- Windows 11
- Windows 10

※将来的にマルチデバイスに対応予定

---

# 3. 対応予定機器

## v0.1

- EQIS-1

## 将来対応

- 自作震度計（ESP32）
- Raspberry Pi
- その他対応機器

---

# 4. 基本機能

- 観測機との接続
- 観測データ受信
- データ表示
- ログ保存
- サーバー送信
- 設定保存

---

# 5. 画面構成

## ホーム

表示内容

- 接続状態
- 観測機名
- 現在震度
- PGA
- 最終受信時刻

---

## 設定

- 観測点名
- Station ID
- 緯度
- 経度
- サーバー設定

---

## ログ

- 地震履歴
- エラーログ
- 通信ログ

---

# 6. データ

受信データ

- 時刻
- PGA
- 推定震度
- センサー状態

送信データ

- Station ID
- 観測データ
- ソフトウェアバージョン
