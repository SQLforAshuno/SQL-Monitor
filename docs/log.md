# 11. アカウント・観測点管理

## 11.1 観測者（Observer）

SQL Monitorでは、観測者と観測点を分離して管理します。

観測者は、SQL Networkへ観測データを提供するユーザーを指します。

### 登録情報

- Observer ID
- 表示名
- メールアドレス
- 登録日時

本プロジェクトでは、観測ネットワークの運用に不要な個人情報を
原則として収集しません。

---

## 11.2 ローカル利用

SQL Monitorは、SQL Networkへ接続せず、
ローカルで観測機を利用することができます。

ローカル利用では、観測者アカウントを必須としません。

```text
SQL Monitor
    │
    └── ローカル観測
          ├── 観測機接続
          ├── データ表示
          └── ログ保存
