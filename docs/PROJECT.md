# SQL Monitor

> 全国の観測者を、ひとつのネットワークへ。

SQL Monitorは、Sapporo Quake Labが開発するオープンソースの地震観測プラットフォームです。

市販・自作を問わず様々な地震観測機と連携し、全国の観測者同士がリアルタイムで観測データを共有できる環境の構築を目指しています。

---

# プロジェクトについて

現在、個人で地震観測を行っている方々は、市販の観測機や自作観測機など様々な環境で観測を行っています。

SQL Monitorは、それらの違いを問わず観測データを一つのプラットフォームへ集約し、リアルタイムで共有できるソフトウェアとして開発しています。

単なる観測ソフトではなく、全国の観測者をつなぐネットワーク基盤を目指しています。

# 開発方針

SQL Monitorは、特定の観測機専用ソフトではありません。

様々な観測機が同じネットワークへ参加できるよう、共通仕様による設計を目指します。

また、観測者同士が協力しながらプロジェクトを成長させるオープンソースプロジェクトとして開発を進めます。
